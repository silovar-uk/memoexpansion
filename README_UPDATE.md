# MemoTool 2.0.4 更新内容

## 主な修正

- アウトライナー本文が右端で見切れないよう、長文・URL・空白なし英数字を領域内で折り返し
- サイドパネル幅を変更した際、表示中の本文・詳細欄の高さを自動再計算
- 行の操作ボタン幅を実測し、本文と重ならない余白を自動確保
- 420px以下では追加日時を隠し、固定表示中の追加操作を本文下へ移動
- 深い階層ではインデント幅を圧縮し、本文領域を確保
- 行番号表示時の狭幅レイアウトを調整
- 詳細欄・URLボタンにも横幅制約を追加

## 更新方法

1. Chromeの `chrome://extensions/` を開く
2. デベロッパーモードをオン
3. 既存拡張機能のフォルダーを、このフォルダーの内容で置き換える
4. 拡張機能カードの「更新」ボタンを押す
5. サイドパネルを閉じて開き直す

## 確認済み

- `sidepanel.js` の構文チェック
- `background.js` の構文チェック
- `manifest.json` のJSON検証
- Manifestバージョン: `2.0.4`
